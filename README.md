## Projects

- ✨ **[MAGI Launcher](https://github.com/Nyaldee/MAGI-Launcher)** — Tentacular, keyboard-only app launcher for Windows — native Rust, zero runtime dependencies, no packer or bundled runtime to unpack on launch.
- ✨ **[CASPER Shot](https://github.com/Nyaldee/CASPER-Shot)** — Global-hotkey screenshot capture, saved as WebP.
- ✨ **[Ports Launcher](https://github.com/Nyaldee/Ports-Launcher)** — A library manager and installer for unofficial native game ports and recomps. Fully portable, with zero runtime dependencies, and compatible with Windows, Linux, and Android. Written in Rust.
- **[Nyaldee Homepage](https://github.com/Nyaldee/Nyaldee-Homepage)** — Personal browser homepage/new-tab replacement: zero dependencies, pure HTML5/CSS/vanilla JS, fuzzy search and collapsible link categories, theme shared with MAGI Launcher/Ports Launcher.
- **[lain.bat](https://github.com/Nyaldee/lain.bat)** — Interactive batch script to optimize and de-bloat a fresh Windows 11 install.
- **[Orange Pi 5B Guide](https://github.com/Nyaldee/Orange-Pi-5B-Guide)** — Personal Ubuntu Server configuration guide for an Orange Pi 5B: SSH/system hardening, eMMC preservation, firewall, systemd services.
- **[AutoHotkey qwerty-french](https://github.com/Nyaldee/AutoHotkey-qwerty-french)** — AutoHotkey v2 script adding a French accented-character layer on a physical QWERTY keyboard, plus window/desktop/media shortcuts.
- **[gists](https://gist.github.com/Nyaldee)** — Assorted config files too small to warrant their own repo.
- **[NieR:Automata PlayStation Button Prompts](https://github.com/Nyaldee/NieR-Automata-PlayStation-Buttons)**
