## Nyaruhodo

Small, lightweight tools, each a single executable with nothing to install. Downloads and documentation in **[nyaruhodo](https://github.com/Nyaldee/nyaruhodo)**, more on [nyaruhodo.com](https://www.nyaruhodo.com/).

- ✨ **[MAGI Launcher](https://github.com/Nyaldee/nyaruhodo/tree/main/MAGI%20Launcher)** — Tentacular, keyboard-only app launcher for Windows and Linux: fuzzy search, calculator, window switcher, timer, sticky notes, clipboard history, USB eject and over 100 color themes.
- **[CASPER Shot](https://github.com/Nyaldee/nyaruhodo/tree/main/CASPER%20Shot)** — Screenshots of a screen or a region by global hotkey, copied to the clipboard and saved as WebP.
- **[Solar RIP](https://github.com/Nyaldee/nyaruhodo/tree/main/Solar%20RIP)** — Two-way patcher for the `.rip` format, for Windows and Linux, with no size limit: the same patch applies and restores.
- **[Silent CMD](https://github.com/Nyaldee/nyaruhodo/tree/main/Silent%20CMD)** — Runs a command or script with no console window, from a shortcut or the Task Scheduler.
- **[Truncate](https://github.com/Nyaldee/nyaruhodo/tree/main/Truncate)** — Gives a file the exact size you want: create it, extend it, shrink it or shift its content.

## Projects
